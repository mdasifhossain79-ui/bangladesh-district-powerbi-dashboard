# Bangladesh District Population Dashboard (Power BI)

An interactive Power BI dashboard that analyzes population, area, density and administrative data for the districts of Bangladesh.


## Objective

To turn raw district-level data into a clear, interactive view that shows how population and density are distributed across divisions and districts.

## Dataset

District-level data for Bangladesh with these fields:

- Division and District
- Year established
- Area (km²)
- Population (2022)
- Density (per km²)
- Seats in Parliament
- Number of Upazilas

## Key Insights

- Total population across all districts: about 165.9 million
- Top 3 districts by population: Dhaka, Chittagong and Cumilla
- Dhaka is the most populated district at about 14.7 million

## Dashboard Features

- Total population KPI card
- Top 3 population districts bar chart
- Division and district level breakdowns
- Custom dark theme and formatting

## Tools and Skills

- Power BI Desktop

- Data modeling and cleaning
- Data visualization
